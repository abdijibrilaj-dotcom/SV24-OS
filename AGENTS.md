# Hinweise für KI-Coding-Assistenten

Dieses Projekt ist ein normales, aktuelles Next.js 15 (App Router) Projekt.
Es gibt keine projektspezifischen Abweichungen von der offiziellen Next.js-
Dokumentation (https://nextjs.org/docs) zu beachten.

Stack: Next.js 15 (TypeScript, App Router, Server Actions), Prisma/PostgreSQL,
NextAuth v5 (Credentials/JWT), Tailwind CSS v4. Siehe README.md für die
vollständige Projektübersicht (Portale, Datenmodell, Deployment).
